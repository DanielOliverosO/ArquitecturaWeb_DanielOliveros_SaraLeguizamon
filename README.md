# Sistema de Reservas - Arquitectura Hexagonal

Este proyecto contiene la estructura base y las clases necesarias para implementar un **sistema de reservas** utilizando la arquitectura hexagonal, desarrollado con el framework **Spring Boot**.  
El objetivo principal es servir como punto de partida para construir una aplicación modular, escalable y fácil de mantener.

## ★ Tecnologías utilizadas
- Java 17
- Spring Boot 3.5.7
- Maven
